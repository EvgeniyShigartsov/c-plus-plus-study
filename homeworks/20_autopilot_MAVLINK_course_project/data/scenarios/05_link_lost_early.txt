# 05_link_lost_early: HEARTBEAT оператора зникає майже одразу після Engaged і не повертається (120 секунд - довше за будь-яку місію)
# Разом з HEARTBEAT зникає і призначення цілей, автопілот мав би доводити наведення до точки скиду, екстраполюючи останню відому
# позицію/швидкість цілі, але HEARTBEAT мовчить уже понад 5 секунд - скид відміняється та чекає на відновлення зв'язку, місія не завершується.
# Очікується: Armed -> Engaged -> Failsafe -> Complete, "refusing to drop, waiting"
# Якщо зв'язок втрачено, і інформація по цілям вже сильно не актуальна, а інших сенсорів немає - нема сенсу робити скид снаряду
# який дуже ймовірно вже не влучить в ціль.

0.2 designate_targets
0.5 enable
1.0 heartbeat_drop 120
