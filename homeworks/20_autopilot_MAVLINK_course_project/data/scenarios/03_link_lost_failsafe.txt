# 03_link_lost_failsafe (1 з 3 failsafe-сценаріїв): HEARTBEAT оператора пропадає надовго,
# але вже під кінець польоту (t=15) - автопілот сам, у Failsafe, доводить атаку до кінця, не чекаючи оператора.
# Разом з HEARTBEAT пропадає і призначення цілей (обрив зв'язку = ми більше нічого не знаємо про цілі), тож
# автопілот доводить наведення екстраполюючи останню відому позицію/швидкість цілі.
# Час підібрано так що "швидкі" тести встигають завершитись ще до обриву (без Failsafe),
# а "повільні" - провалюються у Failsafe (або відмова від скиду, див. сценарій 05).
# Очікувано: або чисто Armed -> Engaged -> Complete (швидкі тести), або
# Armed -> Engaged -> Failsafe -> Complete, без повернення в Engaged (повільні).

0.5 enable
