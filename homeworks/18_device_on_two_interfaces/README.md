# Задачі:

1. Читати дані датчика з реального світу.
2. Надсилати команди на плату, для зміни конфігурацій (у мене період опитуваня)

# Запуск

1. Активувати venv у терміналі: `source ~/.espressif/tools/activate_idf_v6.1.sh`
2. Зібрати: `cd homeworks/18_device_on_two_interfaces && idf.py build`
3. Прошити й відкрити монітор: `idf.py -p /dev/cu.usbmodemXXXX flash monitor` (порт дізнатись через `ls /dev/cu.usb*`)
4. Вихід з монітора — Ctrl+]

Підключення звукового датчика: `+` → `3V3`, `G` → `GND`, `AO` → `GP4`.

Команди в консолі: `p <мс>` змінює період циклу (100-1000 мс за ТЗ), наприклад `p 1000`. Відповідь: `ok: period=1000 ms` або `err: unknown command`.

Щодо використання usb_serial_jtag_read_bytes - плата має нативний USB (USB Serial/JTAG). Консоль вже виводить дані через цей канал, тож вирішив скористатись ним для надсилання команд. Той самий кабель через який встановлюється прошивка слугує і для вводу команд.
